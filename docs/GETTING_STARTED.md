# Getting started (no coding needed)

1. **Open AgentGuard** in your browser. The first time, it asks you to create the administrator account.
2. Press the **three-line button** at the top left. This is the menu: every page is in there.
3. Open **Connect an agent** and choose:
   * **Try it now**: run a pretend agent with one click and see what AgentGuard notices. Nothing to install.
   * **Connect my own agent**: a guided path. You name the agent, create a key, download one small file, run it with Python, and the page confirms the connection. Python is the only thing you need to install, once (python.org/downloads, tick “Add python.exe to PATH”).
   * **Ask a developer**: copies a ready-made message with everything a developer needs to connect a real agent.
4. Go back to **Overview**. It shows one sentence about how healthy your agents are, four numbers, and the problems to fix first.

The file from “Connect my own agent” sends **one sample run**, so you can see the connection work. It does not run your real agent. Connecting a real agent takes a developer and the SDK (docs/SDK_GUIDE.md).

## Who can do what
See docs/ROLES_AND_ACCESS.md. In short: viewers look, members act (approvals, benchmarks, connecting agents), admins manage people, keys, rules and settings.
